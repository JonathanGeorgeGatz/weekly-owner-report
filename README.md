# The Weekly Owner Report

One page every Monday: what sold, what it cost, where the cash went — from the two exports you already have (your register's sales export and your bank's spending export).

**Use it right now:** open [the tool](https://jonathangeorgegatz.github.io/weekly-owner-report/) — everything runs in your browser, nothing is uploaded anywhere.

**Download:** [Weekly_Owner_Report_BUNDLE.zip](Weekly_Owner_Report_BUNDLE.zip) — the tool, the fictional sample business, the exact three prompts typed on camera, the first build's engine (the one that read a Wednesday export as "down 73%"), and the independent Python checker.

What it does: last-complete-week report with a 4-week baseline, an honest week-to-date strip, every bank row landing somewhere (Uncategorized is a bucket, not a void), duplicate-charge flags, refused rows with line numbers and reasons, and a to-the-cent self-audit that prints DO NOT TRUST THIS REPORT when the numbers don't tie.

Built on camera in **Episode 12 of Build It With AI**. All sample data is fictional.
